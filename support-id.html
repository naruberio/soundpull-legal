Memasukkan file ke SoundPull

Dari mana saja saya bisa membuka file?

Pilih Video membuka pemilih Foto, yang hanya menampilkan video. Dari Files menerima video maupun file audio. Anda juga bisa mengirim file ke SoundPull dari lembar berbagi aplikasi lain, termasuk Memo Suara. Jika Anda membagikan beberapa file sekaligus, SoundPull mengambil file yang pertama. File yang dibagikan saat SoundPull sedang sibuk akan ditahan sampai aplikasi luang, dan layar memberi tahu bagaimana file itu akan dimulai; jika ada file lain yang datang sementara itu, hanya yang terbaru yang menunggu.

File audio apa saja yang bisa dikonversi?

M4A, MP3, WAV, AAC, CAF, AIF/AIFF, dan FLAC. File audio melewati langkah yang sama dengan video: Anda bisa memotong satu bagian, menyamakan volume, mentranskripsikannya, dan menyimpan hasilnya dalam format keluaran mana pun. Video tanpa suara memerlukan gambar, jadi selama opsi itu aktif, hanya video yang dapat dipilih.

Mengapa akses perpustakaan foto disebut?

iOS mewajibkan setiap aplikasi menjelaskan alasannya membaca video dari Foto. SoundPull hanya membaca video yang Anda pilih di sana, dan tidak pernah memindai atau mengunggah perpustakaan Anda.

Konversi, penggabungan, dan nada dering

Format apa saja yang bisa dibuat SoundPull?

M4A (AAC), MP3, WAV, dan M4R untuk nada dering. SoundPull juga dapat mengekspor salinan video yang suaranya dilepas; gambarnya tidak dikodekan ulang, sehingga kualitasnya tidak berubah.

Bagaimana cara menyambung beberapa file menjadi satu?

Ketuk Gabungkan audio di bagian bawah layar beranda, tambahkan dua atau lebih video atau file audio, lalu susun urutannya dengan tombol ↑ dan ↓ di samping setiap item. Item yang tidak berisi audio, atau yang tidak dapat dibaca SoundPull, tidak dimasukkan, dan layar memberi tahu berapa jumlahnya. File gabungan memakai format keluaran yang dipilih di layar itu. Jika "Samakan volume" aktif di layar beranda, satu penyesuaian volume diterapkan pada seluruh file gabungan.

Bisakah saya mengonversi banyak file sekaligus?

Bisa. Ekstrak massal, yang juga ada di bagian bawah layar beranda, menerima beberapa video atau file audio dan memprosesnya satu per satu dengan format keluaran yang sama.

Mengapa nada dering saya ditolak?

Nada dering iPhone paling panjang 30 detik. Untuk satu file, potong dulu bagian yang panjangnya 30 detik atau kurang. Untuk penggabungan, total durasinya harus tetap dalam 30 detik, dan jika SoundPull tidak dapat membaca durasi salah satu item, nada dering tidak akan dibuat dari kumpulan itu. iOS tidak mengizinkan aplikasi memasang nada dering sendiri: bagikan file M4R ke GarageBand atau Files, lalu atur dari sana.

Transkrip dan subtitle

Bahasa apa yang dipakai?

Bahasa yang diatur di iPhone Anda; bahasa itu ditampilkan sebelum Anda mulai. Pengenalan hanya berjalan di perangkat, jadi fitur ini hanya bekerja bila iPhone Anda memiliki pengenalan ucapan di perangkat untuk bahasa tersebut. Jika tidak ada, SoundPull memberi tahu bahwa fitur itu tidak tersedia, alih-alih mengirim audio ke tempat lain.

Bagaimana cara mendapatkan subtitle?

Setelah transkripsi selesai, ketuk Simpan subtitle (SRT) untuk membagikan file .srt yang dapat dimuat oleh aplikasi penyunting dan pemutar video. Setiap subtitle dibuat pendek dan dipotong di akhir kalimat atau di jeda. Tombol ini hanya muncul bila iOS memberikan pewaktuan untuk kata-katanya; teks biasa selalu tersedia melalui Simpan / Bagikan teks.

Seberapa akurat hasilnya?

Itu bergantung pada bahasa, rekaman, dan kebisingan di latar belakang. Rekaman panjang dikenali per bagian yang kemudian disambung, jadi bacalah teksnya sampai selesai sebelum Anda mengandalkannya.

Pesan yang mungkin Anda lihat

"Video ini tidak memiliki trek audio."
File tersebut tidak berisi suara yang bisa diambil SoundPull. Putar file itu di Foto atau Files untuk memeriksa apakah ada suaranya.
"Konten terlindungi tidak dapat digunakan. Gunakan video milik Anda."
File tersebut dilindungi DRM, seperti film atau acara yang dibeli atau disewa dari toko. SoundPull tidak memproses konten yang dilindungi dan tidak menembus perlindungan salinan.
"Ruang penyimpanan kosong tidak cukup untuk mengekstrak."
SoundPull memeriksa ruang yang tersedia sebelum menulis hasilnya. Kosongkan sebagian penyimpanan, lalu coba lagi.
"Pengenalan suara di perangkat tidak tersedia untuk bahasa ini di iPhone ini."
Lihat Transkrip dan subtitle di atas.
"File ini tidak dapat diproses."
Format atau codec-nya tidak dapat dibaca. Jika hal ini terus terjadi pada jenis file yang umum, silakan tulis kepada kami dengan menyertakan keterangan yang disebutkan di awal halaman ini.

Pembelian, perangkat lain, dan pengembalian dana

Apakah ada hal lain yang perlu dibeli di dalam aplikasi?

Tidak. SoundPull adalah aplikasi berbayar sekali beli dengan semua fitur sudah termasuk. Di dalamnya tidak ada pembelian dalam aplikasi, langganan, maupun iklan.

Bagaimana cara memasangnya di iPhone lain?

Masuk dengan Akun Apple yang Anda pakai untuk membeli SoundPull, lalu unduh kembali dari App Store tanpa biaya. Aplikasi ini tidak memiliki langkah pemulihan tersendiri.

Bagaimana cara mendapatkan pengembalian dana?

Keputusan atas pengembalian dana untuk pembelian di App Store ada di tangan Apple. Anda dapat mengajukannya di reportaproblem.apple.com.

Mengapa SoundPull meminta saya memberi rating?

Setelah ekstraksi atau penggabungan yang berhasil untuk ke-3, ke-15, dan ke-50 kalinya, SoundPull meminta iOS menampilkan jendela rating standar Apple, dan iOS yang memutuskan apakah jendela itu benar-benar muncul. Anda dapat mematikan permintaan seperti ini untuk semua aplikasi di app Pengaturan, pada App Store, bagian Peringkat & Ulasan Dalam App (In-App Ratings & Reviews).

File dan data Anda

Ke mana file saya pergi?

File Anda tetap di iPhone Anda. Konversi, penggabungan, dan transkripsi semuanya berlangsung di perangkat, dan SoundPull tidak punya server untuk dikirimi apa pun. Setelah sebuah pekerjaan selesai, ketuk Simpan / Bagikan untuk menyimpan hasilnya ke Files, mengirimnya lewat AirDrop, atau meneruskannya ke aplikasi lain. Hasil yang tidak Anda simpan akan dihapus oleh SoundPull.

Bagaimana menghapus seluruh data yang disimpan SoundPull?

Hapus aplikasinya. iOS ikut menghapus pengaturan dan file kerja apa pun milik aplikasi, sementara file yang Anda simpan di tempat lain tetap berada di tempat Anda meletakkannya.
